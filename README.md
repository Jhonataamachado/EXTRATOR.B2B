# 📊 Extrator de Leads B2B (Python)

Automação em Python criada para acelerar a prospeção de clientes B2B.

## 🚀 O Problema que Resolve
Vendedores, corretores e equipas comerciais perdem horas a procurar contactos de empresas manualmente. Este script recebe uma lista de CNPJs e gera, em segundos, uma planilha limpa com **Nome da Empresa, Telefone, E-mail e Cidade**, pronta a usar em campanhas de vendas e cold calling.

## 💻 Tecnologias
Python 3: Lógica de extração e manipulação de ficheiros.
Requests:  Comunicação eficiente com APIs públicas de dados empresariais.
CSV: Geração automática da base de dados de contactos.

## 🤝 Quer esta automação para a sua equipa?
Posso adaptar este script para extrair dados por segmento (ex: "Clínicas de Estética") ou integrar os resultados diretamente no seu CRM. Entre em contacto para adquirir a sua versão personalizada e poupar horas de trabalho manual!
